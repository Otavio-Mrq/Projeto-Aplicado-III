Schulz S.A. — Sistema Web de Calibração MetrológicaProjeto Aplicado III — Faculdade SENAI SC (UniSENAI)Empresa Parceira: Schulz S.A. — Unidade Usinagem / Laboratório de MetrologiaTema: Automação e Digitalização do Processo de Calibração Metrológica e Validação do Erro Máximo Permissível (EMP)📌 Visão Geral do ProjetoO calibracao-web é a aplicação MVP (Produto Mínimo Viável) desenvolvida como entrega final (AV3) do Projeto Aplicado III. O sistema automatiza a ingestão, validação, cálculo e geração de pareceres metrológicos a partir de dados de medição de instrumentos da fábrica da Schulz S.A. (ex: paquímetros, micrômetros, relógios comparadores e manômetros).O projeto consolida as três etapas do ciclo de vida da solução:AV1 (Modelagem de Negócio e Dados): Modelagem do Dicionário de Dados relacional, regras de negócio metrológicas (RN01 a RN05) e critérios de aceitação metrológica.AV2 (Arquitetura em Nuvem): Arquitetura serverless e microsserviços na AWS (Amazon S3, AWS Lambda, Amazon RDS PostgreSQL e Amazon SNS).AV3 (MVP Prático e Web): Aplicação frontend/backend web para upload de planilhas de campo, cálculo automático de incertezas e geração do Certificado Digital de Calibração.🚀 Funcionalidades Principais📂 Ingestão e Sanitização Automatizada: Upload de planilhas no formato .xlsx/.csv contendo medições repetidas ($L_1, L_2, L_3$). Tratamento automático de separadores decimais e remoção de inconsistências.⚙️ Motor Metrológico Avançado:Cálculo da Média das Leituras ($\bar{L}$).Determinação do Erro Sistemático ($E = \bar{L} - V_{\text{nominal}}$).Avaliação de Incerteza Tipo A (desvio-padrão das repetições) e Incerteza Combinada/Expandida ($U$, $k=2$).📊 Regra de Decisão Metrológica (RN02):APROVADO: $\vert{}\text{Erro}\vert{} + U \le \text{EMP}$ (Atende à tolerância de processo dentro da faixa de confiança de 95,45%).APROVADO CONDICIONAL: $\vert{}\text{Erro}\vert{} \le \text{EMP}$, mas $\vert{}\text{Erro}\vert{} + U > \text{EMP}$.REPROVADO: $\vert{}\text{Erro}\vert{} > \text{EMP}$.🛡️ Trava de Validade do Padrão RBC (RN01): Verificação imediata do status de calibração do Padrão de Referência. Bloqueio automático do lote se o padrão estiver vencido.🌡️ Validação de Condições Ambientais (RN03): Registro de Temperatura ($20^\circ\text{C} \pm 2^\circ\text{C}$) e Umidade Relativa (40% a 60%) com emissão automática de ressalva técnica no parecer.📄 Relatórios e Certificados Digitais: Exportação do relatório em PDF/HTML com Hash de Integridade SHA-256 e QR Code para auditorias do SGQ (ISO 9001 / IATF 16949).🏗️ Arquitetura do SistemaA aplicação integra a interface Web com o ecossistema Serverless projetado para a nuvem AWS:[ Planilha Excel / Ingestão Web ]
